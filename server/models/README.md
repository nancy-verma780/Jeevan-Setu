# Wound model

Put the two files produced by `ml/JeevanSetu_Train_Wound_Model.ipynb` here:

- `wound_model.onnx`
- `wound_model.json`

Restart the server. Photos are then analysed and staff can switch on the Grad-CAM focus view.
Without these files the app still works: photos are checked, stored and marked "Not analysed".
